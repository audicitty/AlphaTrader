## 6. Sentiment Analysis Workflow

```
User Clicks "Analyze News Sentiment" Button
  │
  ├─► Check NEWS_AVAILABLE Flag
  │   └─► Not available? → Show warning & return
  │
  ├─► Display Loading Spinner
  │   └─► "📰 Fetching and analyzing news..."
  │
  ├─► Call fetch_news_articles(symbol, company_name)
  │   │
  │   ├─► Initialize NewsAPI Client
  │   │
  │   ├─► Strategy 1: Search by Company Name
  │   │   ├─► Query: "{company_name}"
  │   │   ├─► Language: English
  │   │   ├─► Sort by: publishedAt
  │   │   └─► Page size: 20
  │   │
  │   ├─► Strategy 2: Search by Ticker Symbol
  │   │   └─► Query: "{symbol}"
  │   │
  │   ├─► Combine & Deduplicate Articles
  │   │   └─► Remove duplicates by URL
  │   │
  │   └─► Return Top 20 Valid Articles
  │
  ├─► Call calculate_sentiment_metrics(articles)
  │   │
  │   ├─► For Each Article:
  │   │   ├─► Extract title + description
  │   │   ├─► Call analyze_sentiment_score(text)
  │   │   │   └─► VADER SentimentIntensityAnalyzer
  │   │   │       └─► Returns compound score (-1 to +1)
  │   │   │
  │   │   ├─► Classify Sentiment
  │   │   │   ├─► Score > 0.05? → Positive
  │   │   │   ├─► Score < -0.05? → Negative
  │   │   │   └─► Otherwise → Neutral
  │   │   │
  │   │   └─► Store: {title, source, published, sentiment, url}
  │   │
  │   ├─► Calculate Aggregate Metrics
  │   │   ├─► Average sentiment
  │   │   ├─► Standard deviation
  │   │   ├─► Positive/Negative/Neutral counts
  │   │   └─► Sentiment trend (recent vs older)
  │   │
  │   └─► Determine Sentiment Strength
  │       ├─► |avg| > 0.3? → "VERY POSITIVE/NEGATIVE"
  │       ├─► |avg| > 0.15? → "POSITIVE/NEGATIVE"
  │       └─► Otherwise → "NEUTRAL"
  │
  ├─► Call generate_sentiment_recommendation()
  │   ├─► avg > 0.3 & strength = "VERY POSITIVE"? → "STRONG BUY"
  │   ├─► avg > 0.15? → "BUY"
  │   ├─► avg > 0.05? → "WEAK BUY"
  │   ├─► avg < -0.3 & strength = "VERY NEGATIVE"? → "STRONG SELL"
  │   ├─► avg < -0.15? → "SELL"
  │   ├─► avg < -0.05? → "WEAK SELL"
  │   └─► Otherwise → "HOLD"
  │
  ├─► Display Results
  │   ├─► Main Recommendation Card (Buy/Sell/Hold)
  │   ├─► Sentiment Metrics (avg, strength, counts)
  │   ├─► Visualizations
  │   │   ├─► Sentiment Distribution Histogram
  │   │   └─► Sentiment Timeline Chart
  │   ├─► Top 20 News Articles
  │   │   └─► Sorted by: Sentiment Impact / Date / All
  │   └─► Trading Strategy Suggestions
  │
  └─► Calculate Confidence Score
      ├─► Article count factor (15+ = high)
      ├─► Sentiment strength factor
      ├─► Consistency factor (low std dev)
      └─► Trend clarity factor
```

## 7. Risk Metrics Calculation

```
Input: DataFrame with Price Data
  │
  ├─► Calculate Daily Returns
  │   └─► returns = Close.pct_change().dropna()
  │
  ├─► Check QuantStats Availability
  │   │
  │   ├─► AVAILABLE → Use QuantStats Functions
  │   │   ├─► Sharpe Ratio: qs.stats.sharpe(returns)
  │   │   ├─► Sortino Ratio: qs.stats.sortino(returns)
  │   │   ├─► Max Drawdown: qs.stats.max_drawdown(returns)
  │   │   └─► Calmar Ratio: qs.stats.calmar(returns)
  │   │
  │   └─► NOT AVAILABLE → Manual Calculations
  │       ├─► Sharpe Ratio
  │       │   └─► (mean_return * 252) / (std_return * sqrt(252))
  │       │
  │       ├─► Sortino Ratio
  │       │   ├─► Downside returns = returns[returns < 0]
  │       │   └─► mean_return / downside_std
  │       │
  │       ├─► Max Drawdown
  │       │   ├─► Cumulative returns
  │       │   ├─► Running maximum
  │       │   └─► Max of (cum_return - running_max)
  │       │
  │       └─► Calmar Ratio
  │           └─► Annualized return / |max_drawdown|
  │
  ├─► Calculate Additional Metrics
  │   ├─► Volatility (Annualized)
  │   │   └─► std(returns) * sqrt(252)
  │   │
  │   ├─► Value at Risk (95%)
  │   │   └─► 5th percentile of returns
  │   │
  │   └─► Win Rate
  │       └─► Count(positive returns) / Total returns
  │
  ├─► Package Results into Dictionary
  │   └─► {sharpe, sortino, max_drawdown, volatility, var_95, calmar, win_rate}
  │
  ├─► Display Metrics in UI
  │   ├─► Row 1: Sharpe, Sortino, Max DD, Volatility
  │   └─► Row 2: VaR, Calmar, Win Rate
  │
  └─► Generate Risk Assessment
      ├─► Sharpe > 1? → "Good risk-adjusted returns"
      ├─► Max DD > 20%? → "High drawdown risk"
      └─► Display colored alerts
```

## 8. Stock Comparison Process

```
User Enters Symbols: "MSFT,GOOGL,TSLA,NVDA"
  │
  ├─► Parse Input
  │   ├─► Split by comma
  │   ├─► Strip whitespace
  │   └─► Convert to uppercase
  │
  ├─► Validate Input
  │   ├─► Less than 2 symbols? → Show warning
  │   ├─► More than 10 symbols? → Show warning
  │   └─► Valid count? → Continue
  │
  ├─► Display Loading Spinner
  │   └─► "Fetching data for {n} stocks..."
  │
  ├─► Call fetch_multiple_stocks(symbols, period)
  │   │
  │   ├─► For Each Symbol:
  │   │   ├─► Create yf.Ticker(symbol)
  │   │   ├─► Fetch history(period)
  │   │   ├─► Fetch info dictionary
  │   │   │
  │   │   └─► Store Data:
  │   │       ├─► history: DataFrame
  │   │       ├─► current_price
  │   │       ├─► name, sector, industry
  │   │       ├─► market_cap, pe_ratio, beta
  │   │       └─► dividend_yield, margins, growth
  │   │
  │   └─► Return: {symbol: data_dict}
  │
  ├─► Create Normalized Price Chart
  │   ├─► For each stock:
  │   │   └─► Normalize: (price / first_price) * 100
  │   │
  │   └─► Plot all on same chart (base = 100)
  │
  ├─► Calculate Comparison Metrics
  │   │
  │   ├─► For Each Stock:
  │   │   ├─► Calculate Returns
  │   │   │   ├─► 1-month return
  │   │   │   ├─► 3-month return
  │   │   │   └─► 1-year return
  │   │   │
  │   │   ├─► Calculate Volatility
  │   │   │   └─► Annualized std deviation
  │   │   │
  │   │   ├─► Calculate RSI
  │   │   │   └─► 14-period RSI
  │   │   │
  │   │   └─► Calculate Relative Strength
  │   │       ├─► Fetch S&P 500 data
  │   │       └─► Stock return - S&P return
  │   │
  │   └─► Create Comparison DataFrame
  │       └─► Columns: Symbol, Name, Price, Market Cap, P/E, Beta,
  │           Div Yield, Returns, Volatility, RSI, Rel Strength, Sector
  │
  ├─► Display Results
  │   ├─► Normalized price chart
  │   ├─► Detailed metrics table
  │   └─► Download CSV button
  │
  ├─► Generate Key Insights
  │   ├─► Best 1Y return
  │   ├─► Lowest volatility
  │   └─► Best relative strength
  │
  └─► Show Sector Distribution
      └─► Pie chart of stocks by sector
```

## Performance Optimization Flow

```
User Request
  │
  ├─► Check Cache
  │   │
  │   ├─► Cache Hit?
  │   │   └─► YES → Return cached data (Fast!)
  │   │
  │   └─► Cache Miss?
  │       └─► NO → Fetch fresh data
  │           │
  │           ├─► Store in cache with TTL
  │           │   ├─► Market data: 5 min TTL
  │           │   ├─► Stock data: 1 hour TTL
  │           │   └─► Comparison: 10 min TTL
  │           │
  │           └─► Return data
  │
  ├─► Lazy Loading
  │   ├─► Only fetch when tab is accessed
  │   ├─► Sentiment: Only when button clicked
  │   └─► Screener: Only when "Run" clicked
  │
  └─► Efficient Calculations
      ├─► Use pandas-ta when available (faster)
      ├─► Vectorized operations (no loops)
      └─► Pre-calculate common metrics
```

## Error Handling Strategy

```
Every Function Call
  │
  ├─► Wrapped in try-except
  │
  ├─► Error Occurs?
  │   │
  │   ├─► Log Error (optional)
  │   │
  │   ├─► Display User-Friendly Message
  │   │   ├─► st.error() for critical errors
  │   │   ├─► st.warning() for warnings
  │   │   └─► st.info() for information
  │   │
  │   ├─► Provide Fallback
  │   │   ├─► Return empty DataFrame
  │   │   ├─► Return default values
  │   │   └─► Skip optional features
  │   │
  │   └─► Show Traceback (in expander)
  │       └─► For debugging purposes
  │
  └─► Success?
      └─► Continue normal flow
```
